# ⚡ Enterprise AI OS

An Autonomous Multi-Agent Operating System where 8 specialized AI agents collaborate to complete business tasks.

## 🤖 Agents
- CEO Agent — Strategic Orchestrator
- Research Agent — Market Intelligence  
- Sales Agent — Revenue Engine
- Marketing Agent — Growth Strategy
- Finance Agent — Financial Intelligence
- Operations Agent — Process Control
- Web Intelligence Agent — Web Research
- Memory Agent — Context Memory

## 🚀 Tech Stack
- **Frontend:** React + TypeScript + Vite + TailwindCSS + Three.js + Framer Motion
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL
- **AI:** Groq (Llama 3.3 70B)
- **Agents:** LangGraph + LangChain

## ⚙️ Setup

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
